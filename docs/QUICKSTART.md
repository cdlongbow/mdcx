# 5 分钟上手

第一次用 MDCx，按下面几步走，5 分钟就能刮出一部影片的信息。

## 第一步：准备工作

下载 Release 包（或从源码运行）后，打开程序会看到软件界面。

## 第二步：设置刮削目录

1. 点左侧导航「软件设置」→「刮削目录」标签页
2. 在「待刮削视频目录」右边点浏览，选你放视频文件的文件夹
3. 「成功输出目录」可选，设置后刮好的文件会复制一份过去
4. 别忘点页面底部蓝色的「保存」——设置页所有改动都要保存后才生效

## 第三步：选刮削网站

1. 点「软件设置」→「刮削网站」标签页
2. 在「有码网站」列表里勾选你想要的源（javbus、javdb_app 一般就够了）
3. 直接在列表里拖拽调整顺序，排在前面的优先用

如果刮的是无码、FC2、国产、欧美影片，在对应的标签页里设置。

## 第四步：开始刮削

1. 回到主界面（可先用只放 1 个视频的文件夹试跑）
2. 点顶部「开始」，程序自动扫描刮削目录并开始并发刮削，日志区实时输出进度

等一会儿，你会看到日志区在跑数据。刮完后：
- 视频文件旁边会多一个同名的 `.nfo` 文件（里面是影片信息）
- 如果勾选了下载图片，还会多一个文件夹放海报、缩略图
- 文件会被重命名（按你设置的命名规则）

## 第五步：检查效果

用 Emby、Jellyfin 或 Kodi 打开媒体库，刷新一下，应该能看到多了一张海报墙。
