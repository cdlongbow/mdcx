# 使用手册

日常使用 MDCx 会遇到的各种操作和问题。

## 界面说明

主界面分成几块：

- **顶部**：工具栏（开始、停止、播放等按钮）
- **左侧**：导航栏（主界面、日志、工具、Emby演员管理、NFO库管理、设置、检测网络、使用说明）
- **中间**：主工作区（待刮列表、刮削结果树「成功/失败」、封面预览）
- **底部**：进度条和状态信息

设置界面通过左侧导航「设置」进入，分为 12 个标签页（刮削目录、刮削模式、刮削网站、下载、命名、翻译、字幕、水印、NFO、演员、网络、高级）。网站的连通性与可用状态在左侧导航「检测网络」页查看。

## NFO 库管理

左侧导航「NFO库管理」页面用于浏览和批量编辑已刮削的 NFO 文件：

1. 点击「选择目录」选择 NFO 所在文件夹，自动递归扫描生成文件列表
2. 顶部筛选框支持按番号/演员/标题关键词过滤列表
3. 点列表项读取 NFO，中栏表单可编辑番号、标题、演员、发行日、导演、制作商、系列、评分、简介、标签等 15 个字段
4. 右栏同步预览本地海报和缩略图，「裁剪封面」可调起裁剪工具
5. 点击「保存当前 NFO」时自动对比改动并弹窗确认（字段级 diff），无改动不写盘
6. 批量操作面板：列表顶部「全选/全不选」或 Ctrl+点击勾选多条后，一键替换演员名、加标签、删标签、统一系列名
7. 列表右键菜单：重新刮削（找同目录同名视频入队）、打开所在目录、删除 NFO

## 基本操作流程

### 1. 配置媒体路径

设置 → 刮削目录：
- **媒体路径**：放视频文件的文件夹
- **成功输出目录**：（可选）处理好后复制一份到另一个地方
- **软链接路径**：（可选）创建软链接的目标目录

### 2. 选网站源

设置 → 刮削网站：
- 按影片类型分别配置：有码、无码、FC2、国产、欧美、素人
- 每个类型可以选多个网站，拖动排序决定优先级
- **免 CF 通道**（javdb_api、javdb_app、missav_api、r18dev、thejavdb_api）默认已加入网站源，稳定性好可优先使用

### 3. 字段优先级

设置 → 刮削网站 页每个类型旁的「字段优先级」按钮：
- 每种字段（标题、简介、演员、海报等）都可以独立配置来源网站顺序，也可勾选「跳过」不从任何来源抓取
- 比如标题优先用 JavBus，评分优先用 DMM
- 每种刮削类型（有码/无码等）还可以有不同的字段优先级配置

### 4. 配置下载

设置 → 下载：
- 勾选需要下载的内容：海报、缩略图、背景图、剧照、预告片
- 人脸裁剪：开启后自动检测人脸位置裁剪海报
- Amazon 高清封面：从 Amazon 搜索高清图
- 官方图源兜底（默认开启）：图源全部失败时直构官方 CDN 高清图——DMM 高清封面（自动学习厂牌前缀）+ MGStage 素人高清海报
- JavDB 系图源自动无水印：刮削到 javdb 图床的封面/海报/剧照时自动改走 JavDB App 无水印原图（加密流透明解密，无需配置）

### 5. 翻译（可选）

设置 → 翻译：
- 选翻译引擎（Google / Bing 不需要配置，直接用）
- 选需要翻译的字段
- 可选启用简繁转换

### 6. 命名规则

设置 → 命名：
- 用 Jinja2 模板定义文件命名规则
- 常用模板：`[{{ number }}]{{ title }}`（扩展名由程序自动追加）
- 也可以单独设置文件夹命名和 Emby 标题展示格式

### 7. 开始刮削

1. 回主界面，点「开始」，程序自动扫描刮削目录中的全部视频并开始并发刮削（新用户建议先用只放 1 个文件的目录试跑）
2. 看日志区跑进度，结果树的「成功/失败」列表随每个文件完成而实时更新
3. 刮完后处理失败项：右键「重新刮削」（输入正确番号重刮）或「输入网址重新刮削」（指定详情页网址重刮）

## 四种模式怎么选

| 你的需求 | 选哪个模式 |
|---------|-----------|
| 新下了视频，要完整的海报墙 | 正常模式 |
| 只要按番号归类文件，不要图片 | 整理模式（视频模式） |
| 已有 NFO，要调整目录结构 | 更新模式 |
| 维护已有媒体库，补刮或更新 | 读取模式 |

详细区别看 [FEATURES.md](FEATURES.md) 的「四种刮削模式」。

## 常见问题

### 安装和运行

**装 Python 依赖报错**：
```bash
uv sync --dev
```
如果报某个包找不到，先确认网络能连 PyPI。

**Linux 界面花屏或打不开**：
```bash
sudo apt install libxcb-xinerama0 libxcb-cursor0
export QT_QPA_PLATFORM=xcb
```

**界面太大或太小**：设置 → 高级 → 高分屏缩放，选一个合适的比例，保存后重启。

### 刮削问题

**刮不出数据**：
1. 检查设置里有没有勾选对应类型的网站
2. 点左侧导航「检测网络」页的「开始检测」，看网站可不可达
3. 配置代理（设置 → 网络）

> 小技巧：站点选择下拉框会记住你最近一次检测结果（✅绿圆点=可连通、⚠️黄=需关注、❌红=连不通，悬停可看检测时间与是否走代理），跑过一次检测后即可据此挑选网站；其中 **dmm/mgstage 需要日本节点**、**javdb/javdb_api 不能使用日本节点**（下拉框中有后缀标注）。

**有的网站一直失败**：可能是被墙了。试试：
- 改用免 CF 通道（javdb_api、javdb_app、missav_api、r18dev、thejavdb_api，默认已加入网站源）
- 或者配置外部 CF 服务（设置 → 网络 → 外部 CF 服务，填 TRAWL / FlareSolverr 地址）
- JavLibrary 遇 Cloudflare JS challenge 时会自动 fallback 到 Selenium+Edge headless 获取页面（cf_selenium_bypass，默认开启，需要 Windows 10/11 + Edge 浏览器，无 Edge 环境优雅降级，连续失败 3 次进入 5 分钟冷却）

**刮出来的标题是日文/英文**：设置 → 翻译，开启翻译并选 Google 或 Bing。

### 演员数据库

**数据库在哪**：`userdata/actor_database.xlsx`

**工具页操作**：工具页「演员库维护」区域有十一个操作——补全中文名（按 TMDB ID 补翻译）、补全 LibreDMM 链接、补全别名（可选来源：TMDB、minnano 或 JavDB；默认仅补缺别名的行，勾选「全量更新」则并入全部行且不覆盖本地已有别名；配套「起始行/限量」分片续跑——中断后日志输出"将起始行填入 N-1 即可续跑"，处理日志带 [行N] 前缀便于人工定位，长任务无需从头重发请求）、JavDB 中文名（从 JavDB 移动端 API 查询演员中文名/繁体名，仅处理「中文名 == 日文原名」的行，用 name_zht 转简体补全，无需 TMDB API Key，支持分片续跑）、minnano 补全（从 minnano-av 补缺生日/简介，日文字段自动翻译）、检查用户库（扫描格式/结构/数据异常并弹窗报告，安全项可一键自动修复，tmdb 项给人工修复步骤）、剔除男演员、校验 tmdbid 有效性、更新 nfo tmdbid、打开演员数据库、停止当前维护任务。前九个自动扫描数据库并批量处理，打开用系统默认程序打开 xlsx 供手工编辑，停止按钮独立于主界面刮削停止、一键请求停止当前维护任务（会保存已处理部分，可再次运行继续）。每个联网维护工具默认限量 5000 条逐片处理，配合幂等可多次运行完成全部 2 万+ 行。进度实时显示在日志页。

**数据库坏了**：有备份就用备份恢复。可以定期备份这个文件。

**演员 TMDB ID 查不到**：
- 换几种名字搜（日文名、别名）
- 先去 TMDB 网站确认这个演员有没有收录
- 手动在 Excel 里填上 TMDB ID

**TMDB 请求太快报错（429）**：调低并发数（建议 3），开启限流（默认每秒 3.5 次），等一会儿再试。

**Emby 演员头像上传不成功**：
- 检查 Emby 地址和 API 密钥是否正确
- 确认网络能通 Emby 服务器
- 使用左侧导航「Emby演员管理」查看具体错误信息

**Emby 4.9 剧照不显示**：v2.0.1 已修复，`behind the scenes` 目录下同时保留 .jpg 和 .mp4，兼容新旧版 Emby。

### 网络

**怎么拿 TMDB API Key**：
1. 打开 https://www.themoviedb.org/
2. 注册账号
3. 在设置里申请 API Key
4. 填到 MDCx 设置里

**配置代理**：设置 → 网络 → 代理，支持 HTTP/HTTPS/SOCKS5。只对"走代理网站"域名列表中的站点走代理，其他默认直连；默认列表包含 `amazon.co.jp, m.media-amazon.com, xcity.jp, minnano-av.com, avbase.net, javbus.com, javdb.com, javlibrary.com, r18.dev, mgstage.com, prestige-av.com, seesaawiki.jp, avsox.click, avsox.com, avmoo.shop, avmoo.com, avheat.shop, avheat.com, heyzo.com, caribbeancom.com, 1pondo.tv, pacopacomama.com, 10musume.com, mywife.cc, github.com, raw.githubusercontent.com, google.com, missav.ws, missav.ai, missav.live, aventertainments.com, javfree.me`，可按需追加。

**CF Bypass 落地白名单**：设置 → 网络 →「Bypass落地白名单」可填写可信落地域名（逗号分隔，支持 `*.example.com` 子域通配，如 `javbus.com,*.javdb.com`）。用于校验 Bypass 服务落地/重定向后的最终域名，防止第三方 Bypass 服务被劫持时把恶意页面当数据写入 NFO；留空表示不校验（默认）。

**刮削中途退出，重开要重新刮一遍吗**：不用。刮削进度会自动保存到本地数据库（`userdata/scrape_state.db`，WAL 模式 SQLite），重启后再次刮削会自动跳过已完成且未变化的文件、恢复上次失败的文件（最多自动重试 3 次），从上次进度继续。数据库损坏时会自动回退到全量刮削，不影响使用。**读取模式不受断点续刮缓存干扰**，始终处理全部选中文件。如需清除缓存重新全量刮削，可使用工具页的「刮削缓存管理」功能重置或清空。

**NFO 在 Emby 里显示不出来**：
- 确认刮削时勾了「下载 NFO」
- 刷新 Emby 媒体库
- 检查 NFO 文件格式是否正确

## 实际场景

### 场景：新建媒体库

第一次用 MDCx 建立完整媒体库的操作路径：

1. 安装好程序，设置媒体路径
2. 刮削设置里配好有码/无码网站源
3. 下载设置勾选海报、缩略图、NFO，开启人脸裁剪
4. 翻译选 Google，勾标题和简介
5. 选正常模式，扫描 → 勾选全部 → 点开始
6. 等刮完后，在 Emby 添加媒体库指向输出目录，刷新
7. 再到左侧导航「Emby演员管理」里同步演员信息到 Emby

### 场景：日常补新片

每周下载新视频后的操作：

1. 把新视频扔到媒体文件夹
2. 开 MDCx，点「开始」——断点续刮会自动跳过已刮削且未变化的文件，只刮新增和失败的
3. 检查失败列表，右键「重新刮削」或「输入网址重新刮削」单独处理

### 场景：补充缺失的封面/缩略图

刮削完成后发现某个影片缺少封面图或缩略图：

1. 进入左侧导航「工具」页面，找到「封面补图」区域
2. 输入番号（多个番号用空格分隔，如 `SSIS-001 ABF-371`）
3. 勾选「覆盖已有图片」可重新下载已存在的封面
4. 取消「添加水印」可跳过水印步骤
5. 点击「开始补图」，进度和结果输出到日志页

工具会自动复用当前配置的站点优先级、命名、裁切和水印规则，无需额外配置。

### 场景：找风格相似的影片

刮削完成后想找同风格的其它片（同系列/同片商/同标签）：

1. 在右侧结果树中右键点击任意影片
2. 选择「查看相似片推荐」
3. 弹出对话框按相似度排序展示推荐影片（基于标签/系列/片商/演员等本地离线计算）
4. 双击推荐项可跳转到对应影片（历史结果不在当次结果树中时仅提示番号）

推荐基于全部历史刮削结果（含上次会话），刮削的影片越多推荐越准，全程本地计算无需联网。

所有爬虫站点都拿不到图时，会自动走 **官方图源直链兜底**：① **DMM**：按番号直构 DMM 官方 CDN 高清封面，内置约 110 个主流系列前缀表并自动学习未收录厂牌的前缀（学习数据保存在 `userdata/dmm_prefix_learned.json`）；优先下载 DMM 高清竖版图作海报，竖版不存在时下横版高清图并自动裁剪成海报；无码番号（FC2/HEYZO 等）不会命中 DMM 兜底。② **MGStage**：DMM 不收录的素人番号（LUXU/OTIM 等）直构 MGStage 官方 CDN——横版大图作封面、竖版图作海报。默认开启，可在设置 → 下载「下载高清图」组关闭。

### 场景：管理 Emby 演员头像和简介

Emby 中的演员缺少头像或简介时，可以使用内置的演员管理器：

1. 点击左侧导航「Emby演员管理」打开管理器
2. 在弹窗中填写 Emby 地址和 API 密钥，点击「连接 Emby」
3. 点击「获取演员列表」，选择要管理的媒体库
4. 从下拉框选择获取模式（如「仅全部缺失头像+简介」）
5. 点击「根据设定获取数据」（再次点击可取消），按可配置的数据源优先级从 Gfriends / graphis.ne.jp / minnano-av / 本地文件夹匹配头像和背景图，从本地演员库 / 维基百科 / minnano-av / 数据库匹配简介和出生日期
6. 表格中绿色行表示有更新项，点击「开始全部更新同步」写入 Emby（同步完成后自动刷新演员列表）
7. 「设置」可配置数据源优先级、演员类型过滤/去重、本地头像目录等；「数据源测试」可输入演员名逐源验证结果
8. 双击演员行打开详情编辑对话框：可编辑简介/信息、单独同步头像/简介
9. 「清空缓存文件夹」可清理已下载的头像缓存

注意：API 密钥在 Emby 管理后台 → 高级 → API 密钥中生成。

### 场景：FC2 管理

FC2 番号格式特殊（纯数字或 FC2-PPV-数字），可以在刮削设置里单独配置 FC2 的网站源。

### 场景：调整命名规则

做完一批刮削想改目录结构：
1. 在设置 → 命名里改好新模板
2. 选读取模式，勾选「有 NFO 时更新」
3. 点开始，程序会按新规则重新整理所有文件
