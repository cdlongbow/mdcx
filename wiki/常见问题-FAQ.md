# 常见问题 FAQ

按出现频率排序。问题没解决？欢迎[提议题](https://github.com/cdlongbow/mdcx-diy/issues/new/choose)。

---

## 1. 刮削失败？网络问题占大多数，怎么排查

**排查顺序**：

1. 左侧导航「**检测网络**」页 → 点「开始检测」→ 全量检测所有站点
2. 全红 → 检查代理（见下条）；个别红 → 该站点暂时不可用，属正常
3. 「检测进度」显示 `done/total`，耐心等检测完，**个别站点失败不会中断整轮检测**

**为什么很多站点需要代理**：多数元数据站点部署在海外或对国内 IP 有 Cloudflare 防护。默认「走代理网站」列表已覆盖 javbus/javdb/missav 等 34 个域名，需在本机先跑好代理软件（Clash/v2ray 等），程序默认读 `http://127.0.0.1:7890`。

## 2. 代理只能用 127.0.0.1 吗？（议题 #70）

不是。代理地址支持任意 HTTP/HTTPS/SOCKS5 地址，包括：

- 本地代理：`http://127.0.0.1:7890`、`socks5://127.0.0.1:1080`
- 局域网代理：`http://192.168.1.100:7890`（路由器/NAS 上的代理）
- 远程服务器：`http://your-server:port`

在「软件设置 → 网络 → 代理地址」填写即可。

补充（议题 #83）：「走代理网站」列表支持两种写法——填**域名**（javbus.com）只对该域名生效；填**数据源名**（missav、javdb、7mmtv，可从输入框旁下拉框直接选）则该站点的主域/镜像/备用域名全部自动走代理，站点换域名后无需改配置。旧版本曾存在"下拉框选了数据源名但部分站点仍直连"的问题，已在 2026-09 修复，建议升级。

## 3. 检测网络显示异常/某站点红了的含义

| 显示 | 含义 | 处理 |
|---|---|---|
| 连接正常，刮削正常 | 完全可用 | 无需处理 |
| 站点可达但测试番号未被收录 | 站点通，只是没收录该测试番号 | 忽略（见 #60） |
| 站点可达但被 Cloudflare 拦截 | 需配 CF Bypass 服务或换源 | 设置→网络→CF Bypass |
| 401/403/429 | 缺 Cookie / 被限流 | 补 Cookie（如 JavDb）或稍后再试 |
| 日本 IP 限定 | 需日本节点代理 | 站点列表有「日本IP限定」标注 |

**检测项单项失败不影响其他站点**，某个站挂了换其他源即可。

## 4. 窗口最大化后内容布局乱/不跟随

v2.0.8 已全面修复：软件界面/软件工具/软件日志/检测网络的内容都会跟随窗口缩放；软件设置页全部 12 个 tab（刮削目录/刮削模式/刮削网站/下载/命名/翻译/字幕/水印/NFO/演员/网络/高级）也已同步修复——内容会拉满视口宽度、底部「当前配置/另存为/恢复默认/保存」浮框随窗口底部锚定、滚动到底末行不再被浮框遮挡。如仍遇到，请提议题并附截图（注明窗口模式：原生边框/隐藏边框）。

## 5. 演员管理、信息管理入口可以隐藏吗？（议题 #61/#71）

可以。「软件设置 → 高级 → 隐藏入口」勾选后导航即时隐藏，功能本体保留，随时可重新开启。

## 6. 保存设置没生效 / 切换配置失败 / 卡死内存占满（议题 #55/#69）

v2.0.7 已修复三个根因：旧配置残留站点值导致校验失败、迁移警告被误判、网络栈轮询累积。如再遇到：

1. 备份 `userdata` 目录
2. 删除 `xxx_failed.json`（若出现）
3. 用默认配置重建，逐项导回

## 7. fanart.jpg 变成了 .fanart.jpg.xxx.tmp（议题 v2.0.8）

旧版在 Windows 上复制 fanart 时被杀软/索引瞬时占用导致失败但假报成功。v2.0.8 已三层修复（重试/真实报错/自动清理）。旧残留文件：内容其实是完整图片，**手动改名回 `fanart.jpg` 即可**，或删除后重刮。

## 8. 刮削到的封面有水印/画质差

优先调整站点优先级：JavDB 系（App 无水印通道）> DMM 高清 > 其他。设置 → 站点 → 拖拽排序。详见主仓库 FEATURES.md「图源」章节。

## 9. 软链接是什么？为什么我不能播放

软链接（类快捷方式）适合 PT 保种场景：原文件不动，目标目录放链接。注意很多播放器/媒体服务器**不能直接播放软链接**，仅适合海报墙展示。

## 10. 检测网络提示"自检固定四项"

启动时的自动自检只测基础连通（GitHub/Google 等 4 项），**全量站点检测请到「检测网络」页手动触发**，这是设计如此。

## 11. 番号明明存在但刮不到（议题 #60）

- 先确认番号写法：`SSIS-742` 与 `SSIS742` 都可以，但系列字母不能错
- 用「检测网络」页可输入任意番号单测
- 部分站点收录不全属正常——多站点源会自动互补，个别站点失败不影响整体

## 12. JavDb 提示需要 Cookie

JavDb 网页版搜索 FC2 内容需要登录 Cookie。「软件设置 → 网络 → Cookie设置」里找到 JavDb 那一行，粘贴浏览器里的 Cookie 值；或改用 javdb_app/javdb_api 源（免 Cookie）。

## 13. 大模型翻译超时/失败

- 检查 API Key 有效、账户余额
- 网络代理是否放行 API 域名（多数 LLM 服务商国内直连或需特定代理）
- 系列片/失败重刮的同批文本有缓存，重试成本低

## 14. 更新后旧配置还能用吗

能。配置自动迁移，已删除站点的旧值自动清理，新增站点（如 7mmtv）自动并入默认源。
